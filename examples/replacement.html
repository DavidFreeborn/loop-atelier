Recipe 01 / State replacement

A loop by replacement

Twelve identical clusters travel around a closed path. After one cycle, each cluster occupies its neighbour’s starting place. The whole image repeats while the motion continues.

The same interface, a different loop

The scene returns a reusable buffer of positions and intensities. The renderer asks for the state at a particular phase; it does not need the preceding frame.

import { LoopRenderer }
  from '../src/renderer.js';
import { createReplacementScene }
  from '../src/example.js';

const renderer = new LoopRenderer(canvas);
const scene = createReplacementScene({
  count: 15000, seed: 42
});

// Call with phase between 0 and 1.
renderer.render(scene, phase, {
  pointSize: 1.2, exposure: 0.7,
  camera: {
    yaw: 0.1, pitch: 0.2, distance: 3.4
  }
});

Start by changing the control points in src/example.js. Each queue item uses the same small cloud of samples. Preserve that shared structure when changing its width or brightness.

The seam matches under a permutation of the objects. An individual particle does not return to its own starting point after one cycle. Unique colours, sizes, or random offsets for each cluster would expose the exchange unless those attributes move with it.
